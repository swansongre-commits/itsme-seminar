# It's Me

생성형 AI 기반 교육콘텐츠 설계 세미나에서 시연하는 학습법 탐색 웹 콘텐츠입니다.

**[브라우저에서 체험하기](https://itsme-seminar.onrender.com/)**

## 발표에서 체험할 흐름

1. MBTI, 별자리, 혈액형, 성별, 띠를 고릅니다.
2. **나만 보기**를 눌러 추천 학습법을 읽고, 자신의 공부 습관에 적용해 보고 싶은 방법을 하나 고릅니다.
3. 상대의 항목도 선택하면 두 사람의 분석과 함께 공부할 때의 제안을 볼 수 있습니다.

발표에서 표시되는 성향과 궁합 점수는 재미를 위한 콘텐츠입니다. 학습자 진단이나 실제 관계의 확률을 뜻하지 않습니다.

GitHub Pages에서도 같은 체험 화면으로 이동합니다. 선택에 따른 분석과 학습법 추천은 Render 서버에서 실행합니다.
